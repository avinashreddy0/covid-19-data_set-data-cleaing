🦠 COVID-19 Data Cleaning & Visualization
📌 Project Overview

This project focuses on cleaning a messy COVID-19 dataset and performing data visualization using Matplotlib.
The goal is to transform raw COVID-19 data into meaningful insights through KPIs, charts, and plots.

📊 Key Steps

Data Cleaning

Handled missing values (NaN, null).

Removed duplicate and inconsistent records.

Converted date columns to proper format.

Renamed columns for better readability.

Exploratory Data Analysis (EDA)

Identified trends in cases, deaths, and recoveries.

Grouped data by country and date.

Data Visualization (Matplotlib)

Line charts → Cases over time.

Bar charts → Country-wise comparison.

Pie charts → Proportion of cases.

KPIs → Active cases, recovered, deaths.

📂 Dataset

Source: Open COVID-19 dataset (CSV format).

File used: cleaned_covid19_data.csv.

🛠️ Technologies Used

Python

Pandas → Data cleaning & transformation

Matplotlib → Visualization

NumPy → Numerical operations
